## Product decisions

The Sanctuary access dock reuses the actual Reader icon renderer, named menu action, existing palette and existing visibility guards. Appearance and PDF View retain their original callbacks. A preference controls the existing timer; it does not change page layout, tap grids, hardware keys, progress, selection or TTS. Theme specimen review and navigation dock/rail review use production components. Empty access-component fields deliberately contain no simulated publication.

Archive retrieval gets one visible reading-state disclosure containing all six states; source query/filter/sort derivation remains unchanged. The archive title leads its utility controls, a redundant catalogue-count inscription yields to the actual filtered count, and presentation modes have a visible underline as well as selected semantics.

Castle chambers alternate around the existing stair datum at usable compact widths. At larger text they still stack. Vault-shaped boundaries describe chamber space; a central junction appears only where an actual bridge exists, preventing it from bleeding through room titles. Floor registrations use interface numerals. Rooms, unlock ranks, resonance and routes remain source-derived.
