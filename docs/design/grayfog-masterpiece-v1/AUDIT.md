## Second source review findings

The September Arena audit is historical evidence. Current canonical VeilApp already uses localized typed issue categories and durable game flushes; those systems were retained rather than rewritten. Current Ritual confirmation was a non-scrolling Column with a rigid two-button Row; 200% text could make confirmation/dismissal unreachable. This pass adds vertical scroll and existing adaptive action layout while retaining advancement ownership. Loading receives a static indeterminate register under Reduced Motion.
