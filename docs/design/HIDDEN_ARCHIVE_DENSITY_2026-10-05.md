# Hidden Archive Density Pass — 2026-10-05

## Product problem

Hidden Archive repeated the same five counters twice:
1. a bordered ArchiveRegister;
2. the Notes / Passages / Marks / Echoes / Capsules tabs immediately below it.

That added visual weight without adding retrieval value.

## Change

- remove the duplicate ArchiveRegister;
- keep counts directly on the five section tabs;
- populated Archive uses a smaller title hierarchy and shorter registration rule;
- empty Archive retains the fuller authored entrance;
- divider after section tabs becomes a short registration mark;
- outer spacing uses the semantic Veil spacing vocabulary.

## Preserved

- Notes
- Highlights / Passages
- Bookmarks / Marks
- Echoes
- Capsules
- Search
- note editing
- deletion
- exact passage return
- capsule inspection

No data model or persistence behavior changes.
