## Classification

### A — Correctness / product defects to fix

#### ConfigurationScreenWidthHeight
Two production call sites were still using `LocalConfiguration.screenWidthDp` as their structural adaptive authority:
- Treasury
- Manga Hub

They are switched to `currentVeilWindowSizeDp()`, which follows the live Compose window container and therefore tracks split-screen, desktop resizing and fold/unfold.

The one remaining lint trigger inside `currentVeilWindowSizeDp()` is an intentional bootstrap fallback used only if the live window reports a non-positive size. It is now narrowly documented/suppressed instead of rewriting the fallback into another inaccurate display-size source.

#### DataExtractionRules
`allowBackup=false` alone does not reliably disable device-to-device transfer on all Android 12+ OEM behavior. Add explicit `dataExtractionRules` excluding all app data from cloud backup and device transfer. Veil already has a user-initiated, versioned local backup/export path; implicit platform copy would violate that local-first privacy contract.

#### PluralsCandidate
Treat as a **localization correctness queue**, not an automatic mass rewrite.
- obvious English singular/plural count strings should move to `<plurals>`;
- invariant labels such as “%d complete” must be reviewed individually;
- Persian grammar must be authored deliberately rather than mechanically mirroring English plural categories.

Status: YELLOW; dedicated localization batch required.

### B — Safe performance / allocation fixes

#### AutoboxingStateCreation
Two integer Compose states were unnecessarily boxed:
- Paper debug begin-attempt counter
- PDF probe-generation counter

Both are changed to `mutableIntStateOf`.

### C — Intentional warnings; do not “fix” blindly

#### ApplySharedPref
Most occurrences are deliberate durability boundaries in `GameRepository` and restore code. Replacing `commit()` with `apply()` would weaken persistence semantics and can reintroduce lost-state bugs. These require narrow documentation/suppression if noise becomes a problem, not behavioral replacement.

#### LogNotTimber
Veil does not currently use Timber as a logging architecture. Adding a dependency solely to silence lint is rejected. Review logging privacy/verbosity separately.

#### AppBundleLocaleChanges
The trigger is in debug-only `GrayfogReviewActivity`, used to render locale fixtures. It is not evidence that production dynamic-language delivery is broken. Keep separate from release locale policy.

### D — Cleanup / maintainability

#### UnusedResources
41 resources are candidates for removal, but many are historical strings that may indicate abandoned or renamed UI. Review semantic ownership before deletion.

#### UseKtx
Mostly readability/productivity suggestions. Do not churn durability-sensitive `SharedPreferences` code just to satisfy KTX style.

#### ModifierParameter / ModifierFactoryExtensionFunction / ComposableNaming
API-style cleanup. Batch only when touching the relevant component or during architecture decomposition.

### E — Dependency-update signals

#### Compose
Handled independently by R0.05 qualification.

#### Lifecycle / Fragment / Coroutines / ZoomImage / Gradle
Do not mass-upgrade from lint. Each gets its own compatibility reason and qualification slice.
