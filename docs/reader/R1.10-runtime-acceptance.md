# R1.10 Runtime Acceptance Matrix

This matrix is the runtime gate for the Reader reliability stack after R1.9j.

## Automated host gate

Run on exactly one connected Android emulator or physical device:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/reader-r1-10-device.ps1
```

The script requires `qa/fixtures/veil-smoke.epub` by default and performs:

1. `:app:testDebugUnitTest`
2. `:app:lintDebug`
3. `:app:assembleDebug`
4. `:app:assembleDebugAndroidTest`
5. real EPUB SAF import + Activity rotation/recreation
6. real PDF import + double-tap/pinch/pan + layout toggle + non-initial page + rotation/recreation
7. background the app, kill the app process with `am kill`, recreate the existing Reader task
8. require a `VeilReaderTrace` `reader_open` event with non-zero durable progress
9. fail on crash/ANR

Evidence is written under `app/build/qa/r1-10`.

## Acceptance rule

R1.10 is not GREEN unless all automated gates pass and one physical-device pass confirms:

- EPUB: open -> navigate -> rotate -> background/foreground -> process recreation -> same reading vicinity
- PDF: open -> zoom -> pan -> non-initial page -> rotate -> background/foreground -> process recreation -> same page/vicinity
- close: final locator is not followed by route/checkpoint clear until durable storage acknowledgement
- no stale persisted acknowledgement clears a newer SavedState checkpoint
- no hidden EPUB page-turn preference changes PDF interaction behavior

If recreation fails before Reader UI returns and the stack trace points to constructor-bound Readium navigator restoration, selectively port the minimal FragmentFactory shim from #220. Do not merge #220 wholesale.
