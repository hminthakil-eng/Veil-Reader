# Project Cathedral — Delivery Map

## A. Convergence
Integrate the major design and world-system slices into one coherent source line. Remove duplicate ownership and record conflict decisions.

## B. World Kernel
Create durable world-event history and realm contracts so all visible world mutations are explainable from real reading history.

## C. Great Hall
Transform the existing Castle concept into Veil Above / Great Hall with artifact-based navigation to Archive, Living Mirror, Observatory, Ritual, Treasury, Sanctum and Reader identity.

## D. Living Mirror Notes
Build Spatial and Index modes, deterministic note clustering, temporal depth, revisit/cycle presentation, exact Return to Passage, search focus animation, and an accessibility-equivalent list view.

## E. Archive 4.0
Add temporal strata, physical memory material, sealed cycle dossiers, resurfacing echoes, exact revisit history and deep/recovered archive presentation.

## F. Observatory 3.0
Deliver Constellation, Orbit and Memory Lens modes using factual, provenance-visible relationships.

## G. Ritual and Sanctum
Make advancement visibly change the world. Preserve rare discoveries and long-term artifacts as durable history.

## H. Reader 5.0
Finish paper material, page-block depth, curl release physics, slide/paged/scroll distinction, PDF polish, image lens, selection accessibility and locator durability.

## I. Persian World
Complete localization, Veil lexicon, Persian composition, dates, numerals, RTL layout, mixed-script metadata and Persian accessibility QA.

## J. Motion, Sound and Haptics
Formalize motion classes, H0-H4 haptic grammar, realm material sounds, silence budgets and reduced-motion equivalents.

## K. Runtime Quality
Implement Essential, Balanced, Full and Cathedral fidelity tiers, device/thermal adaptation, shader fallbacks, asset budgets, macrobenchmarks and baseline profiles.

## L. Accessibility and Failure Grammar
Complete TalkBack traversal, semantic equivalents for spatial UI, high contrast, focus order, touch-target audit, corrupt-volume handling, loading tiers and empty states.

## M. Authored Art Pass
Create only high-value authored assets: Great Hall master layers, Sanctum centerpiece, selected seals/relics, rare ritual moments and first-book awakening.

## N. Device Gauntlet
Verify compact/wide/large layouts, low/mid/high hardware, Persian/English, reduced motion, EPUB/PDF, large files, long libraries, rotation, process recreation, memory pressure, startup and screenshot fidelity.

## O. Cathedral Release
Freeze scope, resolve blockers, produce reproducible artifacts tied to a known commit, and promote only after final release gates pass.

## Completion Test

Veil is complete when long-term reading visibly changes the world outside the book, while opening the book removes that world and leaves only a calm, reliable reading surface.
